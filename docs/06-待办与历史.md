## 🚨 重要避坑记录

1. **Cloudflare zone 激活**必须点 `/nameserver-directions` 页的「I updated my nameservers」，
   否则永久 pending（曾卡 50 分钟）。
2. **阿里云改 NS 必须短信验证**，AI 不能代收；验证码输入框是弹窗里 **`type=text` 且无 placeholder** 的那个
   （别填到旁边的 `type=radio`）。
3. **zip 必须用 Python 打**（正斜杠）；`Compress-Archive` 的反斜杠路径 Cloudflare 不识别。
4. **站内链接不要写 `.html`**，否则每条内链都产生一次 307 跳转。
5. **Cloudflare GraphQL 免费版**没有 `referer` / `clientBrowser` 字段，查询需字段回退。
6. **`workers.dev` 域名在国内被污染**，只能用自定义域名测试。
7. **贴吧新号外链会被降级为纯文本**；**知乎想法会吞掉域名**。
8. **每次部署都会生成新 Worker 名**，必须重新绑定自定义域名，否则域名指向旧版本。
