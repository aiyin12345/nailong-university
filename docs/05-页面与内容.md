## 站内互链结构

每个子页面顶部都有一行**全站导航**，指向其余 6 个页面：

```
首页 · 学校简介 · 办学理念 · 校园风景 · 校园新闻 · 常见问题 · 关于本站
```

首页底部的「关于」区块另有第二组站内链接，形成**双向互链**，
帮助爬虫发现全部页面并传递内链权重。

## 内容基调与合规

| 原则 | 做法 |
|---|---|
| **明确非官方** | 每页底部固定声明 + 首页显著段落 + `about` 页专门说明 |
| **不误导** | 反复出现「不招生、不发文凭、无实体校区」「非真实高校」 |
| **给真校导流** | 导航栏、页脚、悬浮球、「按 H 键」均指向 henu.edu.cn |
| **版权尊重** | 声明校名/校徽/影像/奶龙形象版权归原权利方，非商业用途 |
| **有温度** | 虚构内容有趣但不低俗，不使用"招生""录取""文凭"等易误导表述 |
