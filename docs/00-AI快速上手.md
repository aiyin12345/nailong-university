## 🚨 踩过的坑（务必避雷）

1. **Cloudflare 新站点添加后必须走完向导**，否则 zone 永远 `pending`：
   点 `Select plan` → 最后在 `/nameserver-directions` 页面点 **「I updated my nameservers」** → 约 60 秒后激活。
2. **改阿里云 NS 必须短信验证**（手机 `197*****986`），AI 无法代收，需用户提供验证码。
3. **Cloudflare 会把 `/xxx.html` 307 跳到 `/xxx`**（pretty URL）→ 站内链接与 sitemap 必须写无扩展名形式，否则产生重定向链。
4. **PowerShell 的 `Compress-Archive` 生成反斜杠路径**，Cloudflare 上传会失败 → 必须用 Python `zipfile` 且 `arcname` 转成 `/`。
5. **`workers.dev` 域名在国内被 DNS 污染**（解析到假 IP），必须用自定义域名访问。
6. **Cloudflare GraphQL 免费版字段受限**：`referer`、`clientBrowser` 等字段不存在，查询要写渐进式字段回退。
7. **贴吧对新账号会自动把外链降级为纯文本**；**知乎「想法」会直接把域名替换成"链接"二字**（等于没有外链）。

## 🛠 改内容的标准流程

```powershell
# 1) 改站点文件（E:\AIshujuku\ds\henu-dist\ 是发布目录）
# 2) 重新打包（必须用 Python，保证正斜杠）
python -c "import os,zipfile; SRC=r'E:\AIshujuku\ds\henu-dist'; ZIP=r'E:\AIshujuku\ds\henu-site.zip'; ..."
# 3) 部署：跑 E:\AIshujuku\ds\cf_pages_deploy2.mjs（上传并新建 Worker）
# 4) 重新绑定域名：node cf_rebind_domains.mjs <新的服务名>
# 5) 重新推 IndexNow（POST https://api.indexnow.org/indexnow）
```
