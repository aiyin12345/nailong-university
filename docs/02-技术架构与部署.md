### 2. 打包（**必须用 Python，保证正斜杠路径**）

```powershell
python -c @"
import os, zipfile
SRC = r'E:\AIshujuku\ds\henu-dist'; ZIP = r'E:\AIshujuku\ds\henu-site.zip'
if os.path.exists(ZIP): os.remove(ZIP)
with zipfile.ZipFile(ZIP,'w',zipfile.ZIP_DEFLATED,compresslevel=9) as z:
    for root,_,files in os.walk(SRC):
        for f in files:
            p = os.path.join(root,f)
            z.write(p, os.path.relpath(p,SRC).replace(os.sep,'/'))
"@
```

> ⚠️ **不要用 `Compress-Archive`** —— 它写反斜杠路径，Cloudflare 无法识别。

### 3. 部署到 Cloudflare（浏览器自动化）

脚本：`E:\AIshujuku\ds\cf_pages_deploy2.mjs`

关键交互路径（Cloudflare 新版控制台）：

```
Workers & Pages → Create application → Upload your static files
  → 选择 zip → Deploy
```

部署后会生成**新的 Worker 服务名**（如 `tight-sun-4bb8`）。从跳转 URL
`/workers/services/view/<服务名>/production` 提取服务名。

### 4. 把域名重新绑到新 Worker

脚本：`E:\AIshujuku\ds\cf_rebind_domains.mjs <新服务名>`

它通过 Cloudflare API 完成：

```
GET    /api/v4/accounts/{account}/workers/domains          # 列出绑定
DELETE /api/v4/accounts/{account}/workers/domains/{id}     # 删除旧绑定
PUT    /api/v4/accounts/{account}/workers/domains          # 绑定新服务
       body: { zone_id, hostname, service, environment: "production" }
```

### 5. 通知搜索引擎（IndexNow）

```http
POST https://api.indexnow.org/indexnow
Content-Type: application/json
{
  "host": "xn--psszg58cj45k.work",
  "key": "a9384e2c87895bf99d4059522dd5760e",
  "keyLocation": "https://xn--psszg58cj45k.work/a9384e2c87895bf99d4059522dd5760e.txt",
  "urlList": ["https://xn--psszg58cj45k.work/", ".../school", ".../faq", ...]

```
返回 `200 OK` / `202 Accepted` 即成功。

## 已知限制

| 限制 | 说明 | 对策 |
|---|---|---|
| 只能静态 | 无数据库/登录 | 需要时改用 Cloudflare Workers 写 JS |
| 国内访问一般 | 节点在海外/香港 | 主攻百度时考虑国内服务器 + 备案 |
| 百度不友好 | 未备案 + 海外主机 | 需提交百度资源平台；或备案迁国内 |
| Worker 名会变 | 每次部署生成新名 | 部署后必须重绑域名（脚本已封装） |
